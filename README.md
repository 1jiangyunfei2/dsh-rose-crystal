# 玫瑰水晶 · Rose Crystal

**一个适合女生的 DSH 主题**：粉白渐变、果冻键帽质感、黑猫爪发送键，配上会轻轻摆动的猫耳朵输入框。

---

## 这是什么

把 DeepSeek Harness 的默认界面换成一整套玫瑰水晶风格。它不是换一张壁纸，而是把颜色、按钮、装饰一起改：

- **整体配色**：腮红粉白渐变，浅底深字，长时间看不累眼
- **输入框**：上沿有两只小猫耳朵，和输入框连成一体，持续轻摆呼吸
- **发送键**：一颗黑果冻质感的猫爪键帽，粉色掌垫和趾豆
- **按钮**：统一的珍珠键帽风格，悬停会轻轻跳一下，并落下小星星
- **装饰**：四个粉蝴蝶结 + 八颗小星星，错开呼吸摆动
- **输入框下方**：一只小黑猫和两颗粉爱心

## 适合谁

- 喜欢粉色调、希望界面温柔一点的人
- 想要一点点可爱装饰，但不想界面变得花哨难用的人
- 长时间对着编辑器写东西，想让界面看着舒服的人

## 装好之后你会看到

| 位置 | 变化 |
|---|---|
| 背景 | 粉白渐变，带柔光层次 |
| 输入框 | 粉白渐变卡片 + 上沿猫耳朵（会动） |
| 发送键 | 黑猫爪键帽 |
| 普通按钮 | 珍珠键帽，悬停轻跳 |
| 界面四角 | 蝴蝶结与小星星点缀 |

## 设计原则

1. **文字永远清楚**：所有文字都保持深色高对比，不会为了好看牺牲可读性
2. **不遮挡功能**：只改颜色、圆角、描边和装饰，不动任何按钮的位置和功能
3. **动效克制**：所有动画都很轻，且尊重系统的「减少动态效果」设置
4. **不碰你的数据**：纯样式插件，不读取、不上报任何内容

## 兼容性

- 需要 DeepSeek Harness 0.2.x
- 支持浅色与深色两套主题
- 只作用于界面外观，不修改任何功能逻辑
